# Frontend UI/UX Design Skill

## Overview
This skill guides the design and implementation of modern, visually stunning, high-converting, and responsive web applications and components.

## Core Design Principles
1. **Rich Aesthetics & Premium Feel**:
   - Modern color palettes (tailored HSL, dark mode, vibrant accents, sleek glassmorphism).
   - Modern Google Fonts (e.g. Outfit, Inter, Plus Jakarta Sans, Poppins).
   - Subtle gradients (`linear-gradient`, `radial-gradient`) and multi-layered drop shadows.
2. **Dynamic & Interactive**:
   - Hover effects, smooth transitions (`all 0.3s cubic-bezier(0.4, 0, 0.2, 1)`).
   - Micro-animations for feedback (button presses, card hovers, loading skeletons, toast notifications).
3. **Responsive & Fluid Layouts**:
   - Mobile-first layouts using CSS Grid and Flexbox.
   - Dynamic fluid typography (`clamp()`).
4. **Accessibility & Usability**:
   - High contrast text readability.
   - Visible focus states for keyboard navigation.
   - Semantic HTML5 tags (`<main>`, `<nav>`, `<article>`, `<header>`, `<footer>`).

## Standard UI Component Patterns
- **Cards**: Soft borders (`1px solid rgba(255, 255, 255, 0.1)`), backdrop blur (`backdrop-filter: blur(12px)`), lift on hover (`transform: translateY(-4px)`).
- **Buttons**: Glowing active states, subtle scale effects on click (`transform: scale(0.98)`), clear primary vs secondary hierarchy.
- **Form Controls**: Floating labels, clear error states, glowing active focus rings.
