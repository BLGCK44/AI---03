# Agent Superpowers Skill

## Overview
This skill unlocks supercharged problem-solving patterns, autonomous execution techniques, and systematic verification strategies for high-complexity engineering tasks.

## Core Superpowers

### 1. Empirical Bug Diagnostics
- **Never Guess**: Always inspect full error logs, stack trace outputs, and runtime state before forming hypotheses.
- **Trace Upstream**: Trace missing or corrupted data to the upstream provider; never patch symptoms silently.

### 2. Systematic Root-Cause Analysis
- **Isolate Variables**: Change one variable at a time when debugging.
- **Reproduce First**: Formulate a minimal failing test case before attempting fixes.

### 3. Rigorous Verification & Double-Checking
- **Empirical Confirmation**: Never declare success without running actual build, test, or lint commands and inspecting output.
- **Edge Case Audit**: Test boundaries, empty states, network latency, and invalid input formats.

### 4. Zero-Regression Refactoring
- Keep public API signatures backward-compatible.
- Verify callers across the entire codebase using code search before modifying function signatures.
